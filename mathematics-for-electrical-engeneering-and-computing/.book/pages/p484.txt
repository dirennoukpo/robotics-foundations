19.6 Networks
and maximum
flow
                                       A network is a digraph with a weight function. The weight function
                                       represents the number of links between the vertices, for example the
                                       units of traffic (channels) in a communication network, or the maximum
                                       capacity of a network of one way streets in a busy town. This weight
                                                                                                                 t
                                       function value is called the capacity of the arc. An example of a network
                                       is shown in Figure 19.26. s is the source and t is the sink. The capacity
                                       of an arc, ak will be referred to as c(ak ). We wish to find the maximum
                                       possible flow from s the source to the sink t. That is we want to find a
                                       flow function f (ak ) assigning a flow to each of the arcs which gives this
                                       maximum flow.


                                       Flow function
                                       A valid flow function must be such that:
                                       1. f (ak ) ⩽ c(ak ).
                                       2. The out-flow at any vertex equals the in-flow except at the source or
                                          the sink.
                                          An arc is saturated if f (ak ) = c(ak ). The total flow is then the flow out
                                       of s (which equals the flow into t).
