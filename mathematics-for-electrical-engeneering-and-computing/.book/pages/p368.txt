            An example of a non-linear operator is the sine function as

            sin(A + B)  = sin(A) + sin(B)

            For a differential equation the fact that it is linear leads to the fact that
            if a solution to the differential equation with input function f1 (t) is y1
            and a solution to the differential equation with input f2 (t) is y2 , then
            one solution to the equation with an input function af1 + bf2 , is ay1 +
            by2 , where a and b are constants. This result is central to the method of
            solving differential equations used in this chapter and also to the Laplace
            transform method of the next chapter.
