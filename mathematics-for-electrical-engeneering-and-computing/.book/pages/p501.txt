                                   eXtensible Markup Language (XML) is a meta-language, a tool for
                                defining markup languages using tags enclosed in angle brackets < · · · >
                                to start an element of the language and < / · · · > to close an ele-
                                ment. The elements may have properties, called attributes, and child
                                elements. The main reasons for the importance of the development
                                of XML is:

                                1.   XML is a tool for defining markup languages.
                                2.   XML languages can be used to develop standards for the interchange
                                     of data.
                                3.   There are many XML parsers available which will check an XML
                                     document for well-formedness and validity.
                                4.   The structure of XML lends itself easily to a tree representation –
