               A differential equation has many solutions. For instance, the equation
            dx/dt = 3t 2 has solutions x = t 3 , x = t 3 + 4, x = t 3 − 5, etc.
            These are called particular solutions. A general solution is one which
            contains some arbitrary constants and encompasses all possible solutions
            to the differential equation. This means that by choosing values of these
            arbitrary constants we are able to find any of the particular solutions of the
            equation. For instance, x = t 3 + C is a general solution to dx/dt = 3t 2 .
