                                      There are programs that will take a context-free grammar as input
                                   and output the code for the corresponding parser. Such parser genera-
                                   tors are called compiler compilers. Some examples of these are YACC
                                   (Yet Another Compiler Compiler) developed by Bell labs. The GNU
                                   version is called Bison. The Java Compiler Compiler, JavaCC, origi-
                                   nally developed by Sun Microsystems, can be downloaded free from
                                   http://www.webgain.com/products/java_cc/ and runs on most systems.
